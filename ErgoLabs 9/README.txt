ErgoLabs website

Open index.html to start. Keep all files in this folder together.
To host the site, upload the contents of this folder with index.html at the root.

Experiment A is interactive. B, D, G, E and F are clickable Coming soon pages.
The bibliography is a separate page. The essay attachments are not included or published.
All simulation and quiz calculations run locally in the browser.
A browser-tab session flag remembers whether the main explanation was explored, to avoid repeatedly prompting you to start A. No analytics or backend is included.
